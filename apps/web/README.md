# APIProof SaaS Web Application & Dashboard V1

Polished Next.js 15 product website and developer dashboard for APIProof.

## Features & Routes

- `/` — Product Landing Page (Hero, Stripe proof diff, engine architecture, API inventory preview, Bavio real repo proof, security guarantees)
- `/dashboard` — Executive Developer Overview (connected repos, findings summary, recent activity, compatibility health matrix)
- `/dashboard/repositories` — Connected Repositories list with health filter and search
- `/dashboard/repositories/bavio-ai-v1` — Bavio-Ai-v1 detail page (27 Twilio usages, NOT_AFFECTED state, scan breakdown)
- `/dashboard/repositories/apiproof-github-fixture` — Stripe Fixture detail page (Stripe coupon removal finding, AST diff, 4/4 verification matrix, Draft PR #1)
- `/dashboard/inventory` — API/SDK Ecosystem Inventory (Stripe, Twilio, OpenAI, Supabase, Groq, Dodo, Deepgram, ElevenLabs, Sarvam)
- `/dashboard/findings` — Finding list view
- `/dashboard/findings/stripe-subscription-coupon-removed` — Finding detail view with AST code diff, verification log, PR status
- `/dashboard/migrations` — AST migration patch history & verified transformation logs
- `/dashboard/pull-requests` — Review-only draft pull requests generated by APIProof GitHub App
- `/dashboard/activity` — Chronological audit timeline of engine events
- `/dashboard/settings` — GitHub App connection details, notification channels, security policies

## UI Components & Design System

- **Stack**: Next.js 15 (App Router), TypeScript (strict mode), Tailwind CSS, Lucide icons
- **Visual Identity**: Dark-first, technical developer tool styling inspired by Vercel, Linear, and Sentry
- **Command Palette**: Press `Cmd + K` or `Ctrl + K` anywhere in the dashboard to open global search & fast navigation
- **Demo Modal**: Click "Connect Repository" to view the non-destructive GitHub App installation modal

## Architecture & Demo Data

All UI data is driven by strongly typed domain models in `src/lib/demo-data.ts`.

Key domain entities:
- `Repository`
- `ProviderIntegration`
- `ApiUsage`
- `Finding`
- `Migration`
- `VerificationEvidence`
- `PullRequestSummary`
- `ActivityEvent`

This data layer directly reflects empirical APIProof core engine outputs (such as Bavio's 390 source file scan and Stripe fixture's Draft PR #1) and can be connected to real backend APIs in future phases without modifying UI components.

## Local Execution Commands

From workspace root (`C:\YC`):

```bash
# Install dependencies
pnpm install --frozen-lockfile

# Run development server
pnpm --filter @apiproof/web dev
```

Or from `apps/web`:

```bash
pnpm dev
```

Target URL: `http://localhost:3000`

## Quality Gates

```bash
# Typecheck web app
pnpm --filter @apiproof/web typecheck

# Build production bundle
```
